# 🐍 Snake Game: Arena

Um jogo da cobrinha clássico com uma experiência moderna, visual atrativo e desafios adicionais! Desenvolvido utilizando **HTML5, CSS3 e JavaScript Vanilla**, sem necessidade de frameworks ou bibliotecas externas.

O objetivo é controlar a cobrinha, coletar frutas, acumular pontos, avançar de nível e evitar obstáculos, frutas perigosas e uma cobrinha adversária.

## 🎮 Demonstração do Projeto

O jogo funciona diretamente no navegador, sem necessidade de instalação ou configuração de servidores.

## ✨ Funcionalidades

- 🐍 **Movimentação da cobrinha:** controle utilizando as setas do teclado.
- 🍎 **Frutas especiais:** colete frutas para aumentar sua pontuação.
- ☠️ **Frutas perigosas:** evite as frutas roxas, pois elas encerram a partida.
- 🤖 **Cobrinha adversária:** enfrente uma adversária que se movimenta pelo cenário e tenta se aproximar do jogador.
- 🚧 **Barreiras:** desvie dos obstáculos espalhados pela arena.
- 🏆 **Sistema de pontuação:** ganhe 10 pontos a cada fruta coletada.
- 📈 **Sistema de níveis:** avance de nível a cada 100 pontos.
- ⚡ **Dificuldade progressiva:** a velocidade do jogo aumenta conforme o jogador avança.
- 🎨 **Paletas de cores dinâmicas:** a aparência da cobrinha muda conforme o nível.
- 💾 **Recorde salvo:** a melhor pontuação fica armazenada no navegador utilizando LocalStorage.
- 🔄 **Reinício de partida:** jogue novamente após o Game Over.
- 📱 **Layout responsivo:** interface adaptável a diferentes tamanhos de tela.

## 🕹️ Como Jogar

1. Abra o jogo no navegador.
2. Clique no botão **Iniciar jogo**.
3. Utilize as setas do teclado para movimentar a cobrinha.
4. Colete as frutas vermelhas para ganhar pontos.
5. Evite as frutas roxas, as barreiras, a cobrinha adversária e as bordas da arena.
6. Alcance 100 pontos para avançar de nível.
7. Continue jogando e tente superar seu recorde!

### ⌨️ Controles

| Tecla | Ação |
|---|---|
| ⬆️ Seta para cima | Movimentar para cima |
| ⬇️ Seta para baixo | Movimentar para baixo |
| ⬅️ Seta para esquerda | Movimentar para esquerda |
| ➡️ Seta para direita | Movimentar para direita |

## 📊 Sistema de Pontuação

- 🍎 Cada fruta coletada vale **10 pontos**.
- 📈 A cada **100 pontos**, o jogador avança um nível.
- ⚡ A velocidade aumenta progressivamente.
- 🚧 Novas barreiras são adicionadas conforme o avanço dos níveis.
- 🏆 O recorde é atualizado automaticamente quando uma nova pontuação máxima é alcançada.
